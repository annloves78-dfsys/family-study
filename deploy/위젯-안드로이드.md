# 안드로이드 홈 화면 위젯 만들기

아이가 **앱을 열지 않고** 홈 화면 버튼 한 번으로 도장을 찍게 하는 방법입니다.

---

## 먼저 알아두실 것

진짜 위젯(안드로이드 홈 화면에 올라가는 작은 창)은 **네이티브 앱만** 만들 수 있습니다.
도장판은 웹앱이라 직접은 못 만듭니다. 그래서 **HTTP Shortcuts** 라는 무료 앱을 하나
빌려 씁니다. 이 앱이 "버튼을 누르면 정해진 요청을 보내는" 위젯을 대신 만들어 줍니다.

- 아이 폰마다 **한 번씩** 설정해 주면 됩니다
- 설정이 끝나면 아이는 홈 화면 버튼만 누르면 됩니다

---

## 1. 앱 설치

Play 스토어에서 **HTTP Shortcuts** (개발자: Roland Meyer) 를 설치합니다. 무료입니다.

---

## 2. 도장판에서 설정 내용 받기

1. 관리자로 도장판에 로그인
2. 아이 탭을 고르고 → **📱 위젯** 버튼
3. 주소와 Body 두 가지가 나옵니다. 각각 **복사** 버튼이 있습니다

> ⚠ 여기 나오는 Body 는 **그 아이의 열쇠**입니다.
> 카톡·메일로 돌리지 마시고, 아이 폰에 직접 입력해 주세요.

---

## 3. HTTP Shortcuts 에 넣기

앱을 열고 **＋** → **HTTP 요청** 을 고른 뒤:

| 칸 | 넣을 값 |
|---|---|
| 이름 | `연우 공부 1시간` (아무거나) |
| Method | **POST** |
| URL | 도장판에서 복사한 주소 (`...?action=stamp_next`) |

**Request Body** 탭으로 가서:

| 칸 | 넣을 값 |
|---|---|
| Request body type | **Custom text** |
| Content type | `application/json` |
| Body | 도장판에서 복사한 Body |

**Response** 탭에서 (선택이지만 해두면 좋습니다):

| 칸 | 넣을 값 |
|---|---|
| Display type | **Toast** (짧게 뜨는 알림) |

이렇게 하면 누를 때마다 `연우 3/4시간` 같은 안내가 잠깐 뜹니다.

저장하면 끝입니다.

---

## 4. 홈 화면에 올리기

만든 항목을 **길게 눌러** → **홈 화면에 추가** 를 고릅니다.
아이콘이 홈 화면에 생기고, 그걸 누르면 앱이 열리지 않고 도장만 하나 찍힙니다.

---

## 5. 실수로 눌렀을 때

같은 방법으로 하나 더 만들되, 주소만 `...?action=stamp_undo` 로 바꿉니다.
그 버튼을 누르면 그날 **마지막 도장 하나**가 취소됩니다.

이름은 `연우 취소` 정도로 해두시면 됩니다.

---

## 자주 생기는 문제

| 증상 | 이유 / 해결 |
|---|---|
| `로그인이 필요합니다` | Body 를 잘못 붙였거나, 아이가 비밀번호를 바꿨습니다. 도장판에서 **📱 위젯**을 다시 눌러 새로 만드세요 |
| `다른 사람의 도장은 바꿀 수 없습니다` | Body 의 `userId` 와 토큰이 서로 다른 아이입니다. 다시 복사하세요 |
| `방금 눌린 것 같아요` | 두 번 연속 눌렀습니다. 잠시 뒤 다시 누르면 됩니다 |
| 아무 반응 없음 | Response 표시를 **Toast** 로 바꾸면 결과가 보입니다 |
| `지울 도장이 없어요` | 취소 버튼인데 그날 찍은 도장이 없습니다 |

---

## 알아두실 점

- **위젯 토큰은 10년짜리**라 자주 다시 만들 필요는 없습니다.
- 다만 그 아이가 **비밀번호를 바꾸면 위젯도 같이 멈춥니다.**
  (보안을 위해 일부러 그렇게 해뒀습니다 — 비밀번호를 바꾼 이유가
  "누가 내 계정을 쓴다" 일 수도 있으니까요.) 그때는 다시 만들어 주세요.
- 위젯으로 찍는 도장은 **목표 시간 안쪽이면 돈**, 넘으면 **쿠폰(⭐)** 으로
  앱에서 찍는 것과 똑같이 계산됩니다.
- 위젯은 **오늘 날짜**로만 찍힙니다. 어제 것은 앱에서 찍어야 합니다.
- 주소를 `family.anne.ai.kr` 로 옮긴 **뒤에** 위젯을 만드세요.
  먼저 만들면 나중에 주소가 바뀌어 다시 만들어야 합니다.
